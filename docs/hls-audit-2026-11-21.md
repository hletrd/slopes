# HLS 오류 재점검 2026-11-21

서비스에서 사용하는 HLS 70개를 다시 검사했다. 오류가 있는 지산·오크밸리·웰리힐리·휘닉스는 공식 웹캠 페이지와 플레이어 코드/API를 함께 대조했다. **공식 영상 주소는 11월 19일 수정본과 같았으며, 교체 가능한 새 공개 원본은 확인되지 않았다.**

검사 시각: 2026-11-21 04:19 KST (2026-11-20T19:19:56.846Z). 59개에서 영상 조각 수신과 목록 갱신을 확인했고, 11개는 원본 오류가 남았다. YouTube·비발디·외부 위젯은 이번 검사 대상에 포함하지 않았다.

| 리조트 | 공식 페이지 대조 | 현재 오류 |
|---|---|---|
| 지산 | PC 공식 플레이어의 jisan1~5 주소와 일치. 공식 버튼은 26/27 시즌 안내 표시 | 레몬·블루·실버 3개 원본 404. 오렌지와 5/6 슬로프 정상 |
| 오크밸리 | 최신 공식 번들의 ch2·ch5·ch9·ch6·ch7 및 playlist.m3u8 경로와 일치 | 5개 모두 KT CDN 원본 연결 오류(502). HTTP·HTTPS 동일. 공식 플레이어도 영상 미수신 |
| 웰리힐리 | 공식 서버 렌더링 데이터의 cam02~07과 일치 | 정상/광장 cam05 원본 404. 나머지 5개 정상 |
| 휘닉스 | 현재 공식 API의 cctvUrlInfo 7개와 일치 | 베이스·펭귄 목록이 오래된 상태이며 선언된 영상 파일 4개 모두 원본 404. 공식 베이스 플레이어도 재시도 반복 |

11월 19일 중단됐던 **휘닉스 도도는 원본이 복구됐다.** 공식 브라우저에서 1920px 영상 재생을 확인했다. 반면 베이스가 새로 멈췄다. 두 항목의 주소는 바뀌지 않았다.

지산 모바일 페이지에는 오래된 카메라 번호 1·3·6·4·5가 남아 있으나, PC 공식 페이지는 현재 등록 번호 1·2·3·4·5를 사용한다. 모바일의 오래된 번호를 적용해 정상 영상을 잘못 교체하지 않았다. 오크밸리의 HTTP 주소는 공식 HTTPS 페이지에서도 같은 호스트의 HTTPS로 업그레이드되며, 두 프로토콜 모두 502를 반환했다.

이번 검사에는 현재 서비스의 links.json을 사용했다. 저장소의 기본 데이터는 무주 임시 서명과 오투 동적 채널 번호가 최신이 아니므로 이를 그대로 검사하면 장애를 과다 집계한다. 실제 서비스의 갱신된 데이터로는 무주 11개·오투 8개가 모두 정상이다.

주소 변경이 확인되지 않아 재생 주소와 프록시 정책은 수정하지 않았다. HTTPS CDN·외부 서비스는 직접 재생하고, HTTP 전용 영상은 기존 HTTPS 중계를 유지한다. 정상 영상 대신 다른 위치의 카메라나 녹화물을 연결하지 않았다.
